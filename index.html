Reporte de incidencias con ubicación

La aplicación solicita la ubicación únicamente cuando el usuario lo decide, adjunta las coordenadas al reporte y muestra el margen de error de la lectura. Si el permiso se deniega o la ubicación no está disponible, se puede seleccionar una zona manualmente.

Permiso de ubicación

Usaremos tu ubicación una sola vez para adjuntar las coordenadas al reporte y localizar la sucursal más cercana. No se hace seguimiento continuo ni se envían los datos a un servidor.

  • Lectura puntual, sin seguimiento.
  • El navegador mostrará su propio diálogo de permiso.
  • Si no deseas compartirla, puedes elegir una zona manualmente.
